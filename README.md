# 南山小程序 · 原型线框（Prototype Wireframes）

> 面向老年人的**喘息服务双向撮合小程序**低保真原型。
> 老人 / 家属 / 网格员发布陪伴与生活协助需求，时间充裕的大学生另一端接单。

## 这是什么
- 一份**低保真线框**（low-fidelity wireframe），用于快速对齐产品结构与核心交互。
- 纯静态 HTML + CSS 绘制，**无需构建、无需依赖**，双击 `南山小程序原型线框.html` 即可在浏览器查看。
- 共 **11 个页面**：启动/隐私授权、首页（含角色切换与精神文化类入口）、发单页、我的订单、订单详情、接单大厅、任务详情、我的接单、大学生认证（含专业证书上传）、个人中心、**社区食堂信息/核销页**。

## 核心产品模型
- **双向撮合**：需求方（老人本人 / 家属代单 / 网格员代单）发单 → 大学生接单。
- **用户角色生命周期**：角色是标签而非身份，一个用户可同时/先后是「需求方」与「供给方」；大学生志愿服务积累的信用分、志愿时长、陪伴记录，未来本人/父母成为需求方时可直接受益。
- **多层次养老需求**：① 生活照料 ② 健康照护 ③ 精神文化（含琴棋书画）④ 安全应急。
- **生态关联**：政府优惠券、企业赞助与积分、社区食堂、老年人用品/医疗辅助厂家、大学生就业背书（志愿者/实习证明）。

## 技术栈（规划）
- 前端：微信原生 WXML / WXSS / JS / JSON
- 后端：腾讯云 CloudBase（云开发：云数据库 NoSQL 集合 + 云函数 + 云存储）
- 参考课程范式：小滴课堂《微信小程序云开发·仿知乎全栈》

## 如何预览
- **高保真交互原型（推荐）**：用浏览器打开 `prototype.html`，可点击 / 跳转，模拟真实 App 主流程。
- **入口选择页**：`index.html` 可在两种原型之间切换。
- **低保真线框总览**：`南山小程序原型线框.html`（11 页静态线框，桌面并排）。
